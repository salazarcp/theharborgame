### Reading the numbers honestly

The on-site work is close to best-in-class. The score is dragged down by two things, and
neither is a code-quality problem:

1. **Brand Authority 25/100** — the entity barely exists off-site. No Wikidata, no Wikipedia,
   no LinkedIn company page, no press coverage, 884 YouTube subscribers, 128 Discord members.
   This costs 15 weighted points on its own and **cannot be fixed inside this repo.**
2. **Content 52/100** — the rubric puts 50 of its 100 points on Experience and
   Authoritativeness, which are built on first-person accounts, named experts, and third-party
   validation. Harbor has **no named human anywhere on the site**. The writing itself is
   top-decile; the score reflects two fixable absences, not bad content.

### What is already right — do not "fix" these

- **Prerendering is complete and correct.** All 12 routes ship 748–1,281 words of real body
  text, full nav, breadcrumbs and a complete JSON-LD `@graph` to a crawler that runs no JS.
  `src/main.tsx` correctly branches on `container.hasChildNodes()` to `hydrateRoot`, so the
  prerendered DOM is reused rather than discarded. This is the single most common GEO failure
  and this site does not have it.
- **Zero AI-crawler restrictions.** GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot,
  PerplexityBot, Google-Extended, GoogleOther, Applebot-Extended, Amazonbot, FacebookBot — all
  allowed by wildcard. No `X-Robots-Tag` anywhere. `max-snippet:-1` removes the snippet cap,
  which is exactly right for AI quoting. **100/100.**
- **`scripts/verify-seo-pages.mjs` is a genuine build-time SEO regression gate**, wired into
  the Netlify build via `npm run check:seo`. It hard-fails the deploy on an empty root, a
  missing/duplicate H1, a wrong canonical, a broken hreflang trio, a word count under a
  per-page floor, a missing structured-data type, mismatched `og:image` dimensions, encoding
  corruption, and a wrong game title. Well above what most sites this size run.
- **Correct restraint on unverifiable facts.** No `offers`, `releaseDate`, `aggregateRating`
  or `contentRating` in schema — none are announced. `verify-seo-pages.mjs` +
  `harbor-facts.json` form a real anti-hallucination guard. **Keep it.**
- **Hreflang is fully reciprocal** across all six EN/TR pairs, with `x-default` on every page
  and matching `xhtml:link` annotations in `sitemap.xml`.
- **Redirect hygiene is clean**: protocol, host, trailing slash and case each resolve in
  exactly one 301 hop; unknown paths return a hard 404, not a soft-404 SPA shell.
- **IndexNow is implemented properly** — key file plus a Netlify build plugin with its own
  test suite. Matters for GEO specifically: ChatGPT and Copilot both read Bing's index.
- **The editorial posture is the site's best GEO asset.** `/games-like-rust-dayz-scum/`
  answers "Is Harbor better than Rust?" with *"There is no responsible basis for that claim."*
  `/trailer/` refuses to invent a transcript. `llms.txt` carries an "Evidence boundaries"
  section. This is exactly what AI platforms reward for a pre-launch entity.

### H7 — No security headers configured

`netlify.toml` has no `[[headers]]` block at all. `X-Content-Type-Options`, `X-Frame-Options`,
`Referrer-Policy`, `Permissions-Policy` and `Content-Security-Policy` are all absent; HSTS is
Netlify's default without `includeSubDomains`.

**Fix — `netlify.toml`**, append:

```toml
[[headers]]
  for = "/*"
  [headers.values]
    X-Content-Type-Options = "nosniff"
    X-Frame-Options = "SAMEORIGIN"
    Referrer-Policy = "strict-origin-when-cross-origin"
    Permissions-Policy = "camera=(), microphone=(), geolocation=(), interest-cohort=()"
    Strict-Transport-Security = "max-age=31536000; includeSubDomains; preload"
    Content-Security-Policy-Report-Only = "default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' https://fonts.gstatic.com; img-src 'self' data: https:; frame-src https://www.youtube-nocookie.com; connect-src 'self' https://dzmqyzgrechlzkhrxhwp.supabase.co; base-uri 'self'; form-action 'self'; frame-ancestors 'self'; object-src 'none'"
```

Ship as `-Report-Only` first, watch the console for a week, then rename the key.
`style-src 'unsafe-inline'` is required because Tailwind/React emit inline styles. The
`frame-src` and `connect-src` hosts were read from `src/content/gameIdentity.ts` and the

### H8 — Zero caching on content-hashed assets

Measured on `/assets/index-*.js`, `/assets/react-vendor-*.js`, `/assets/index-*.css`,
`/hero-bg.webp`, `/logo.png`: all return `Cache-Control: public,max-age=0,must-revalidate`.

**Fix — `netlify.toml`**, append (note the *different* policy for `public/` images, which are

```toml

    Cache-Control = "public, max-age=31536000, immutable"

[[headers]]
  for = "/*.webp"
  [headers.values]
    Cache-Control = "public, max-age=604800, stale-while-revalidate=86400"

[[headers]]
  for = "/*.jpg"
  [headers.values]
    Cache-Control = "public, max-age=604800, stale-while-revalidate=86400"

[[headers]]
```
